Mise a jour des responsables

Fabrique une page avec les noms deja inscrits dedans. Tout se passe sur ton ordinateur : rien n'est envoye nulle part.

1 Le tableau des responsables

Choisis ton fichier responsables.csv. Il doit contenir au minimum les colonnes cle et nom.

2 Le code de la page

Ouvre ton module HTML dans Confluence, selectionne tout le code (Ctrl+A), copie-le (Ctrl+C) et colle-le ci-dessous. Tu peux aussi choisir directement le fichier .html si tu l'as sur ton poste.

3 Generer

Le resultat apparaitra ci-dessous. Copie-le et colle-le dans le module HTML de Confluence, a la place de l'ancien code.

Choisis un tableau et colle le code de la page pour commencer.
